# opa_rfs example

This is a runnable Flutter application demonstrating `opa_rfs` in a realistic
Flowline workspace landing page. It shows fluid hero typography, responsive
spacing, a dashboard preview, feature cards, radius, shadows, and mobile/desktop
layout changes.

Run it from this directory:

```bash
flutter pub get
flutter run -d chrome
```

Resize the browser window and watch the debug terminal for calculated RFS values.

The web build exposes hash-based routes that work on static hosts without
server-side URL rewriting:

- `/#/demo`
- `/#/laboratory`
